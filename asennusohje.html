Mitä tiedostoja tarvitset
Latasin nämä kolme tiedostoa
🏠 index.html Aloitussivu
🔧 admin.html Optikon hallintapaneeli
📱 nakoharjoitukset.html Urheilijan näkymä
💾 Tallenna nämä kolme tiedostoa samaan kansioon tietokoneellasi, esim. Dokumentit / nakoharjoitus
1
Luo uusi repository GitHubissa
Repository = kansio GitHubissa
1
Mene osoitteeseen github.com ja kirjaudu sisään
2
Klikkaa oikeassa yläkulmassa + -nappia → valitse New repository
3
Kirjoita nimeksi nakoharjoitus (pienillä kirjaimilla, ei välilyöntejä)
Repository name
nakoharjoitus

Visibility
● Public    ○ Private
⚠ Valitse Public — GitHub Pages vaatii tämän ilmaisversiossa
4
Vieritä alas ja klikkaa vihreää Create repository -nappia
2
Lataa tiedostot GitHubiin
Ei koodausta — pelkkä raahaaminen
1
Olet nyt tyhjässä repositoryssä. Klikkaa linkkiä uploading an existing file
(tai navigoi: Add file → Upload files)
2
Raahaa kaikki kolme tiedostoa yhtä aikaa selainikkunaan — tai klikkaa choose your files ja valitse kaikki kolme
3
Odota että tiedostot latautuvat (näkyy palkit). Sen jälkeen klikkaa alhaalta Commit changes -nappia — voit jättää viestikenttään oletustekstin
✅ Nyt GitHubissa pitäisi näkyä kolme tiedostoa listassa: index.html, admin.html, nakoharjoitukset.html
3
Kytke GitHub Pages päälle
Tämä tekee sivusta julkisesti auki olevan webbisivun
1
Klikkaa repositoryn sivulla yläpalkista Settings (hammasratas-ikoni)
2
Vasemmasta valikosta klikkaa Pages
3
Kohdassa Branch — valitse pudotusvalikosta main (tai master) ja sen jälkeen klikkaa Save
Source
Deploy from a branch

Branch
[ main ▼ ]   [ / (root) ▼ ]   Save
4
Odota noin 1–2 minuuttia ja päivitä sivu. Sivun yläosaan ilmestyy vihreä teksti ja osoite:
🌐 Your site is live at:
https://sinunnimesi.github.io/nakoharjoitus/
⏳ Joskus kestää 2–5 minuuttia ennen kuin sivu aukeaa. Jos tulee 404-virhe, odota hetki ja kokeile uudelleen.
4
Kokeile että toimii
Tarkista kaikki kolme osoitetta
1
Avaa selaimessa: sinunnimesi.github.io/nakoharjoitus/
→ Pitäisi näkyä aloitussivu jossa kaksi nappia
2
Klikkaa Optikon hallintapaneeli → käy läpi kaikki 4 vaihetta, luo testiohjela ja klikkaa Avaa urheilijan näkymä
3
Urheilijan näkymässä pitäisi näkyä luomasi harjoitukset nimen kera — ei enää "Demo-näkymä"
🎉 Valmis! Sinulla on nyt toimiva osoite jota voit jakaa urheilijoille tekstiviestillä tai QR-koodilla vastaanotolla.
📱
Ohje urheilijalle: lisää puhelimen aloitusnäytölle
Anna tämä ohje urheilijalle — toimii kuin oikea sovellus
iPhone (Safari)
1.Avaa linkki Safarissa (ei Chrome!)
2.Paina alhaalta Jaa-nappi (neliö jossa nuoli ylös)
3.Vieritä alas → "Lisää Koti-valikkoon"
4.Klikkaa Lisää — sovellus ilmestyy aloitusnäytölle
Android (Chrome)
1.Avaa linkki Chromessa
2.Paina oikealla yläkulmassa ⋮ (kolme pistettä)
3."Lisää aloitusnäyttöön" tai "Asenna sovellus"
4.Klikkaa Lisää — valmis
🔄
Myöhemmin: miten päivitän sovellusta?
Jos haluat tehdä muutoksia
1
Mene GitHubissa repositoryyn nakoharjoitus
2
Klikkaa muokattavan tiedoston nimeä listassa (esim. nakoharjoitukset.html)
3
Klikkaa kynä-ikonia oikealla ✏️ → muokkaa → Commit changes
💡 Jos haluat lisätä uusia harjoituksia tai muuttaa toiminnallisuutta, pyydä minulta päivitetty tiedosto ja lataa se GitHubiin samalla tavalla kuin alussa.
